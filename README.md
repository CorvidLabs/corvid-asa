# Corvid ASA Holder Role Tiers & Perks Website

This repository contains the source code for the Corvid ASA Holder Role Tiers & Perks website. It's a simple static HTML page that displays the different tiers and their associated perks.

## Files Included

- `index.html` - Main page with tier information
- `styles.css` - Styling for the website
- `img/favicon.svg` - Website favicon
- `404.html` - Custom 404 error page
- `README.md` - This file
- `robots.txt` - Search engine indexing rules
- `sitemap.xml` - Sitemap for search engines
- `.gitignore` - Files to exclude from Git

## How to Deploy to GitHub Pages

1. Create a new repository on GitHub (or use an existing one)
2. Upload all files to the repository
3. Go to the repository settings
4. Scroll down to the "Pages" section
5. Under "Source", select "Deploy from a branch"
6. Select the branch (usually `main` or `master`)
7. Click "Save"
8. Your site will be published at `https://[username].github.io/[repository-name]/`

## Customization

You can customize:
- The content by editing `index.html`
- The styling by modifying `styles.css`
- The favicon by replacing `img/favicon.svg`

## Local Development

You can run the site locally by running:

```
fledge run serve
```

This will start a local server for testing.
